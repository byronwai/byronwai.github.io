最近玩緊 [ニラちゃん百鬼夜行](https://nirachanhyakkiyagyou.taidon884.workers.dev/)，一個放係 Cloudflare Worker 上面嘅 survivors-like 網頁遊戲。一局入面揀武器、執經驗珠、升級進化，玩下玩下就一個鐘。不過想睇晒全部進化武器嘅效果，正常玩法要開好多鋪，所以寫咗個小 cheat，一開局就滿晒所有技能。

## 個 cheat

遊戲把成個 game state expose 咗做 `window.__nira`，所以唔需要 hook 任何嘢，直接改 `__nira.G` 就得。貼去 browser console (F12 → Console) 就可以：

```js
// ニラちゃん百鬼夜行 — start every run with all skills mastered
// Paste into the browser console (F12 → Console) on the game page, then press はじめる.
// Applies to the current run and to every new run until you reload the page.
(() => {
  // true  = evolved weapons (火矢, 文禍伝雷, 血のヴェール, 百鬼の灯, 薔薇の檻, しょうがとうにぐり)
  // false = the six base weapons at Lv5 instead
  const EVOLVED = true;

  const nira = window.__nira;
  if (!nira) { console.warn('window.__nira not found — open this on the game page.'); return; }

  const WEAPONS = EVOLVED
    ? ['fire', 'thunder2', 'veil2', 'onibi2', 'rose2', 'cat2']
    : ['bow', 'thunder', 'veil', 'onibi', 'rose', 'cat'];
  const PASSIVES = { candle: 5, crown: 5, stitch: 5, shoes: 5, clock: 5, thread: 5, mirror: 2, moon: 5, lace: 5 };
  const ROSE_ELEMENTS = { ice: 3, fire: 3, bolt: 3, poison: 3, dark: 3 };

  function masterAll(G) {
    G.weapons = {};
    for (const id of WEAPONS) G.weapons[id] = { lv: EVOLVED ? 1 : 5, cd: 0 };
    G.passives = { ...PASSIVES };
    G.roseEl = { ...ROSE_ELEMENTS };
    // Same formulas as the game's recalc(), so stats match the maxed passives
    const P = G.passives, p = G.p;
    p.dmgMul = 1 + 0.1 * P.candle;
    p.maxHp = 100 + 20 * P.crown;
    p.hp = p.maxHp;
    p.regen = 0.3 * P.stitch;
    p.speed = 62 * (1 + 0.08 * P.shoes);
    p.cdMul = 1 - 0.07 * P.clock;
    p.magnet = 60 * (1 + 0.35 * P.thread);
    p.amount = P.mirror;
    p.area = 1 + 0.12 * P.moon;
    p.armor = 1 - 0.08 * P.lace;
  }

  clearInterval(window.__niraMasterTimer);
  let lastRun = null;
  window.__niraMasterTimer = setInterval(() => {
    const G = nira.G;
    if (G && G !== lastRun && nira.state === 'play') {
      lastRun = G;
      masterAll(G);
      console.log('[nira] All skills mastered for this run.');
    }
  }, 100);
  console.log('[nira] Ready — start a run (or keep playing) and everything will be maxed.');
})();
```

## 用法

1. 開 [個遊戲](https://nirachanhyakkiyagyou.taidon884.workers.dev/)，撳 F12 開 Console。
2. 貼上面段 code，Enter。
3. 撳 はじめる 開局 — 六把武器同所有被動即刻晒。

個 script 會每 100ms 檢查一次 `__nira.G`：每偵測到新開嘅一局（物件 reference 變咗）就自動 re-apply，所以唔止當前呢局，之後每局都係滿技，直至你 refresh 個 page 為止。

想玩返基礎版（六把 Lv5 原始武器，唔係進化版）嘅話，把 `const EVOLVED = true` 改做 `false` 就得。改完貼多一次 console 便會用返新設定。

## 原理

其實好簡單：

- `__nira.G.weapons` / `__nira.G.passives` 就係武器同被動嘅 lv 表，直接寫入想要嘅等級。
- 薔薇の檻 嘅屬性強化另存喺 `G.roseEl`，都係照抄滿級。
- 被動加成唔係遊戲自己 recalc 嘅，所以 script 尾段照抄咗遊戲 `recalc()` 嘅公式（`dmgMul`、`maxHp`、`speed`、`cdMul` 呢啲），等面板數值同正常滿被動時一致，唔會出現「數值怪怪哋」嘅情況。

單機遊戲，自娛用途，想睇晒進化效果又唔想農咁耐就幾好用。
