是咁的，話説我 11 尾嘅時候去咗跟童軍同 HARTS 一干人等去咗王兆生領袖訓練中心兩日一夜宿營。今次係我第一次有份幫手教中學生玩 Fox Hunting 同 set 場地，所以寫下籌備嘅心路歷程，順手介紹下。

### Fox Hunting 101

Fox Hunting (Transmitter hunting) 實際上係一班人負責係一個 Area set 好發射 Radio signal 嘅 Beacon，另一班人就帶住地圖同天線接收 Beacon 所發射嘅 signal。天線上面有兩個旋鈕，一個調整接收頻率，一個調整音量。

![image8]({{ site.baseurl }}/assets/images/fox-hunting-saikung/image8.jpg)

接收用 3 element 八木天線 aka 指向性天線

咁我點知自己會收到啲咩？要聽啲咩？點先會贏？

實際上 Beacon 係開機之後會係 144-146 MHz 其中揀一個窄頻率作 CW 發射。人話嚟講等於 Morse code 發送 1 char 數字。由於參賽者手持嘅天線有指向性，要符合以下條件先會係 Headphone 聽到大聲嘅 Morse code:

  - 參賽者距離 Beacon 足夠近
  - 天線指向 Beacon 所在方位
  - 天線接收頻率與 Beacon 發射頻率相近

上述條件符合得越多，你就聽到越大聲。

比賽出發前參賽者會 given 三個數字，佢哋聽到對應數字嘅 morse code 後雖然揾返 Beacon 上面寫住嘅文字。抄收好每個 number 所對應嘅文字之後就可以記錄係分紙上面。

![image2]({{ site.baseurl }}/assets/images/fox-hunting-saikung/image2.jpg)

![image6]({{ site.baseurl }}/assets/images/fox-hunting-saikung/image6.jpg)

Beacon 真貌

舉個例子，Beacon No.1 上面會寫住 Apple，Beacon No.2 寫住 Banana 。參賽者們就要係卡上面寫返 1 號 Apple，2 號 Banan 咁。

每隊參賽者會有 30 分鐘揾自己 Target 嘅 Beacon，揾到 Non-target 都有 Extra 分數。

### Set 場

今次活動係香港業餘電台聯會 (HARTS) 同 深資童軍負責 set 場。我地係沙嘴去三星灣，全場 1.1 km 嘅山路上面沿途佈置 Beacon，合共 set 咗 6 個。大概我地每 70 步 (30m) set 一個 Beacon，接收下一個 Beacon 時候上一個嘅 signal 已經好微弱。

雖然係咁，係路口位置依然會有收到 Multiple Beacon Signal 可能性。的確 AM / CW 發射就會有咁嘅可能性...

### 正賽 (?)

由於不可抗力，我做咗小隊導師要同自己啲仔一齊玩。但係我地要夜晚八點跑山入三星灣，亦即上圖嘅 Point A to Point B。

無日照嘅情況之下我地一行十人，揸住兩支天線聽 morse code。最慘個樣野係乜都睇唔清，沿途返落山嘅時候重要比啲𡃁仔撇低，自己一個人落返山。

![image3]({{ site.baseurl }}/assets/images/fox-hunting-saikung/image3.png)

真係摸黑上山落山

我有同時發現 AM 頻譜分析儀可以幫助收窄搜索範圍， 我拎住部 K6 聽住 144 MHz 範圍，經過 Beacon 已經收到 Morse code，頻率都唔洗調整。唯一問題 Handheld radio 用嘅係全方向天線，無得 monitor Beacon 方向要用腳調整。

![image1]({{ site.baseurl }}/assets/images/fox-hunting-saikung/image1.jpg)

K6 入門其實好好，改壞都唔心痛

最後我個隊係 0 分收場，叫佢哋覆卷又唔聽。

### 後記

Fox hunting 係一個好好嘅 Amature Radio 入門方法，除咗可以做運動之外，仲可以親身感受到天線方向同訊號接收之間嘅關係。

係外國嘅 Fox hunting 範圍會更大，而且 Beacon 之間佢哋超過 3km 以上。北京 2023 都有搞過一次，但係係公園入面搞...

比賽用嘅天線同接收機都要過 500 蚊，Beacon 又要額外 500，好嘅係可以 reuse。

![image9]({{ site.baseurl }}/assets/images/fox-hunting-saikung/image9.png)
